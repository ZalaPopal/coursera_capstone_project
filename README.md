# Coursera Data Analyst Capstone Project

## 📊 Project Overview

This repository contains my **Data Analyst Capstone Project**, completed as part of the **Coursera Data Analyst program**.

The project demonstrates the main stages of a data analysis workflow, including **data cleaning, exploratory data analysis (EDA), statistical analysis, data visualization, and dashboard development**.

The project was completed using **Python, Pandas, Jupyter Notebook, and Power BI**.

---

## 🛠️ Tools & Technologies

* **Python**
* **Pandas**
* **NumPy**
* **Matplotlib**
* **Jupyter Notebook**
* **Power BI**
* **Microsoft Excel / CSV files**

---

## 📁 Project Structure

The project is organized into three main modules:

### Module 2 – Data Cleaning

This module focuses on preparing the raw data for analysis.

Activities include:

* Loading and exploring raw datasets
* Identifying missing values
* Cleaning and transforming data
* Handling incorrect or inconsistent data
* Checking data types
* Preparing a clean dataset for further analysis
* Exporting cleaned data for use in later modules

📂 **Folder:** `Module 2`

---

### Module 3 – Exploratory Data Analysis

This module focuses on understanding the dataset and identifying patterns and relationships within the data.

#### Labs included:

* **Lab 12 – Exploratory Data Analysis**

  * Initial exploration of the dataset
  * Summary statistics
  * Understanding variables and distributions

* **Lab 13 – Finding How the Data is Distributed**

  * Examining data distributions
  * Understanding the spread and characteristics of variables

* **Lab 14 – Finding Outliers**

  * Identifying unusual or extreme observations
  * Investigating potential outliers

* **Lab 15 – Finding Correlation**

  * Examining relationships between variables
  * Identifying correlations within the dataset

📂 **Folder:** `Module 3`

---

### Module 4 – Data Visualization

This module focuses on communicating findings through visualizations.

#### Labs included:

* **Lab 16 – Data Visualization**
* **Lab 17 – Histogram**
* **Lab 18 – Box Plot**
* **Lab 19 – Scatter Plot**
* **Lab 20 – Bubble Plots**
* **Lab 21 – Pie Charts**

These visualizations were used to better understand patterns, distributions, relationships, and comparisons within the data.

📂 **Folder:** `Module 4`

---

## 📈 Power BI Dashboard

The project includes an interactive **Power BI dashboard** designed to analyze technology preferences, future technology trends, and respondent demographics.

The dashboard is divided into three main sections:

### 1. Current Technology Usage

This dashboard explores the technologies currently being used by respondents.

| Panel | Visualization        | Analysis                          |
| ----- | -------------------- | --------------------------------- |
| **1** | Stacked Bar Chart    | Top 10 Programming Languages Used |
| **2** | Stacked Column Chart | Top 10 Databases Used             |
| **3** | Word Cloud           | Top 10 Platforms Used             |
| **4** | Scatter Bubble Chart | Top 10 Web Frameworks Used        |

---

### 2. Future Technology Trends

This section examines the technologies respondents **want to use or learn in the future**.

| Panel | Visualization        | Analysis                           |
| ----- | -------------------- | ---------------------------------- |
| **1** | Stacked Bar Chart    | Top 10 Languages Desired Next Year |
| **2** | Stacked Column Chart | Top 10 Databases Desired Next Year |
| **3** | Tree Map             | Top 10 Desired Platforms           |
| **4** | Scatter Bubble Chart | Top 10 Desired Web Frameworks      |

---

### 3. Demographics

This section provides an overview of the characteristics of the survey respondents.

| Panel | Visualization     | Analysis                                               |
| ----- | ----------------- | ------------------------------------------------------ |
| **1** | Pie Chart         | Respondents by Age                                     |
| **2** | Map Chart         | Respondent Count by Country                            |
| **3** | Line/Bar Chart    | Respondent Distribution by Education Level             |
| **4** | Stacked Bar Chart | Respondent Count by Age, Classified by Education Level |
